# Buleku Manchu Lookup: Firefox Extension

This folder contains the Firefox version of the Buleku Manchu Lookup add-on.

## Install in Firefox

1. Open Firefox.
2. Go to `about:debugging#/runtime/this-firefox`.
3. Click `Load Temporary Add-on...`.
4. Choose `manifest.json` from this folder.

## Notes

- This version is designed for Firefox, including PDF-oriented lookup support.
- If copied text from a PDF is imperfect, edit the query in the lookup window and search again.
